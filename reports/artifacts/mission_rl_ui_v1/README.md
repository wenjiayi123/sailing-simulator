## 使用

重启模拟器，按 N，选择任务并应用，然后点击“启用场景强化学习”。绿色“已接管”出现后按 N 收起即可观看实时自主航行。完成后重新应用任务可再次运行；已启用的合格任务间切换会自动匹配网络。
