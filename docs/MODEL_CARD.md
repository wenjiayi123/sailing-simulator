# 策略与安全监督模型卡 / Model card

## 策略库存

- V1：PPO、SAC、TD3、DQN、LOS-PID，固定公开海况场景。
- V2：PPO、SAC、TD3、DQN、A2C、DDPG、TRPO、LOS-PID、LQR、MPC，长滩港历史 AIS + ENC + 海况的 45 维环境。
- V3：不删除、不重训、不覆盖 V2；对每个 V2 策略新增一个 `base+safety_v3` 组合策略。Safety V3 是运行时模型预测投影层，不是新训练神经网络。

## 预期用途

用于离线自主航行算法研究、失效分析、数据切分实验、安全门禁验证和 Godot 轨迹回放。禁止解释为实船自动驾驶产品、COLREG 认证、船级社认可或商业航行许可。

## 训练与评估

七种 V2 RL 以固定 train split 训练；控制基线不训练。validation 用于冻结产物/配置，test 只在冻结后访问。V2 的 2,000 步/算法是执行覆盖证据，不是收敛声明。V3 对十种基础策略使用同一监督配置，记录干预、fail-closed、碰撞、搁浅、到达、航道/COLREG 代理和运行延迟。

## Safety V3 固定结果

- 完成 72×10 个 validation 和 130×10 个冻结后 test rollout；完整性与哈希验证通过。
- 宏平均碰撞场景率 18.69% → 15.46%，但搁浅场景率 6.15% → 6.23%。
- 干预步占比 55.7%–86.6%，fail-closed 回合占比 11.5%–20.0%。
- LOS-PID/LQR/MPC 的无碰撞到达率分别由 86.9%/70.0%/73.8% 退化至 70.0%/37.7%/62.3%。
- 效用保真审计拒绝全部 10 个组合策略；决策为 `REJECT / FAIL-CLOSED`。V3 不是默认策略，仅作为冻结失败证据与后续研究起点。

## 局限与风险

- 历史 AIS 动作是反事实仿真，不包含真实船舶对本策略的交互响应。
- ENC Direct 派生 GIS 与公开海况不用于在航导航。
- COLREG 指标是保守遭遇代理，不是完整法规推理或法律结论。
- V2 RL 训练预算不足以支持收敛或跨港泛化声明；失败记录是模型卡的一部分。
- SB3 模型可能包含 Python 序列化对象，只能加载哈希已知的仓库产物。

## 变更规则

已有模型、checkpoint、指标、轨迹和失败报告不可原地替换。新增训练策略必须使用新目录和新策略 ID，并在 Godot 策略下拉框中增量展示；旧选项继续保留。核心代码或数据变化必须生成新版本的 prepared/final 报告和哈希。
