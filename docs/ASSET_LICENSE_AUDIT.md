# 资产许可审计

审计日期：2026-07-21

## 发布结论

公开版通过资产许可边界检查，可以按根目录 Apache-2.0 许可证发布项目原生代码、文档、SVG 图标、Godot 场景和着色器。

## 已执行的处理

- 船体、海面、航标、港区障碍和尾流均由 Godot 基础网格或项目源码生成。
- 环境音由 `AudioStreamGenerator` 在运行时合成，不分发录音文件。
- `docs/images/hero.svg`、`architecture.svg`、`social-preview.svg` 与根目录 `icon.svg` 为项目自绘矢量图；GitHub 社交预览 PNG 由对应 SVG 机械渲染。
- README PNG 由 `tools/capture_readme_screenshots.gd` 从当前 Godot 主场景自动捕获；画面只包含项目原生程序化几何与 UI。
- 未复制人物序列帧、照片、纹理、旧场景资产或来源不明的声音文件。
- 未复制软著申请材料、截图、压缩包、本地虚拟环境、缓存和训练输出。
- 默认港区配置和 RL 基准明确标记为项目原生数值数据，不冒充测绘、AIS 或生产数据。

## 第三方内容

仓库仅保存一份带来源元数据的 Open-Meteo 海况缓存，按 CC BY 4.0 署名。Python 和 Godot 是外部运行依赖，不把其源码或二进制文件重新打包进仓库。完整条目见 `THIRD_PARTY_ASSETS.md`。

## 后续贡献要求

任何新增图片、模型、字体、音频或数据集必须在合并请求中提供作者、来源链接、许可证和必要署名。来源不明或禁止再分发的资产不得提交。

自动生成截图也必须检查本机绝对路径、凭据、个人信息和调试覆盖层；发现泄露时应先修复界面源逻辑，再重新生成截图。
