# 多驾驶台协同与驾驶台资源管理

更新时间：2026-08-28

## 已实现

- 岗位：船长、值班驾驶员、舵手、雷达、电子海图、轮机、首部系缆站、尾部系缆站和教员。
- 指令权限：只有船长、值班驾驶员和教员可发送 `COMMAND`；舵手等岗位越权发送会被拒绝并记录回执。
- 闭环通信：目标岗位、类别、消息正文、是否需要复诵、复诵正文、错误岗位和重复确认均有校验。
- 驾驶台资源管理：危险、共同计划、应急/中止方案三要素简报；船长/值班驾驶员/舵手缺岗、未闭环消息和简报缺失会进入团队检查缺口。
- 质疑文化：任何岗位都可发送 `CHALLENGE`，目标岗位必须复诵回应后才形成闭环。
- 组网：实现带会话标识、会话令牌、协议版本和心跳包的本机 UDP 运行通道；运行测试实际绑定随机端口并完成收发。

## 安全边界

- 默认只允许 `127.0.0.1`、`::1` 或 `localhost`；非回环绑定必须由调用方显式授权。
- UDP 包具备训练会话令牌校验，但不加密，不能当作生产网络安全控制。
- 所有消息均记录 `mapped_to_actuation=false`，不会转换为舵、车钟、侧推器或策略指令。
- 这不是甚高频无线电话、全球海上遇险与安全系统或认可的远程驾驶台。
