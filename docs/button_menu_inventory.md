# 全部按钮与菜单清单

本清单来自 `main.tscn` 运行时实例，不是只扫描源码文字。2026-08-15 回归结果：9 个交互面板、116 个按钮/下拉/复选控件全部存在处理器；151/151 项实际点击与状态联动检查通过；36/36 项页面导航和快捷键检查通过。

## 训练控制台（25）

- 船舶：`收起`、船舶选择下拉、`+ 新船`、`克隆`、`删除`、`接管选中`、`下一艘`
- 数据集：`v1 当前场景 / 28维`、`v2 长滩 NOAA AIS+ENC / 45维`
- 算法：v1 为 `PPO / SAC / TD3 / DQN / LOS-PID`；v2 还会由后端合同加载完整方法清单
- 主操作：`导出配置`、`启动训练`、`算法/环境设置`、`运行测试集并渲染`、`停止策略回放`
- 训练弹窗：`终止`、`执行本次训练策略`、`关闭`
- 环境设置：`预览安全边界`、`恢复默认`、`应用`、`关闭`
- 四个 `启用` 复选框：碰撞终止、合并场景障碍、域随机化、评估随机化

- `开始记录`、`结束评分`、`清空本次`、`导出复盘`

## H 全系统 RL 总控（23）

- 总控入口：`进入 RL 训练中心`、`航线规划`、`风险决策`、`海况与时间`、`AIS 船队态势`、`训练与仿真复盘`、`小懿系统助手`、`证据与指标中心`
- 算法下拉：`SAC`、`PPO`、`TD3`、`A2C`、`DDPG`、`TQC`、`TRPO`
- 策略下拉：`SAC-S1 静态 TEST PASS`、`RES-SAC-D2 动态 TEST PASS`、`MANUAL-F0 非RL`、`PERSONAL-LATEST 状态化个人策略`
- 镜头下拉：`自动跟随旋转`、`自由镜头（不跟随）`
- 船体外观固定为 `3D内置双体无人艇`，不是可点击项；原图片船渲染入口已移除
- `0  人工物理可达性验收`
- `1  启动无渲染训练`
- `2  验证策略（不渲染）`
- `3  测试并生成可视化`
- `播放所选策略`
- `停止并恢复原场景`
- `1x`、`3x`、`5x`
- `4  重测动态策略（无渲染→播放）`
- `关闭面板（H）`
- 子面板浮动入口：`← 返回 H 总控｜当前：模块名`

## 快捷键入口

- `M` 证据中心；`Z / X / C` RL 控制台 / 船队 / 训练中心
- `N` 航线规划；`V` 风险决策；`W` 风浪流；`I` AIS；`P` 复盘；`O` 小懿助手
- `H` 全系统 RL 总控核心；`G / K / T` 场景切换 / 测试轨迹 / 昼夜天气
- 方向键控制主船；`A / D` 环绕相机；`R / F` 调整俯仰。自动跟随模式中键盘优先人工接管镜头，松开 1.25 秒后恢复船首航向跟随；自由镜头模式不会自动夺回旋转。

机器可读证据：`reports/godot_button_inventory_v1.json`、`reports/godot_button_interaction_smoke_v1.json`、`reports/godot_ui_navigation_smoke_v1.json`。
