# 顶级研究工程差距审计与闭环

目标口径：顶级开源研究工程与高可信模拟器，不冒充已获批的实船生产系统。

| 优先级 | 初始缺口 | 本轮处置 | 结论 |
|---|---|---|---|
| P0 | V2 十策略碰撞率未过保守准入 | 保留 V2 原始失败；新增独立 Safety V3，完成 720 validation + 1,300 sealed test | REJECT / FAIL-CLOSED；0/10准入，原策略不替换 |
| P0 | 未核验视觉资产阻断整包再分发 | 不删除本地资产；新增不含视觉资产的研究核心可复现包 | 全视觉包继续 BLOCKED |
| P0 | 可能把离线结果误解为生产权限 | 增加生产门禁、威胁模型、模型卡/数据卡；权限字段持续 false | PASS（边界明确） |
| P1 | 模型被替换或误删 | V3 对原有十 checkpoint 和七模型 ZIP 逐项哈希核验 | PASS |
| P1 | 安全层缺少延迟、干预、fail-closed 证据 | V3 记录每策略完整回合、干预步、候选评估、延迟与失败；新增效用保真门禁 | PASS（证据完整）；策略准入 FAIL-CLOSED |
| P1 | 供应链防护不足 | 增加 CodeQL、依赖审查、OpenSSF Scorecard、SBOM 工作流 | PASS（配置） |
| P2 | 复现实验入口分散 | Makefile 增加 V3/研究包门禁，README 串联报告与边界 | PASS |
| P2 | 新旧策略在界面中可能混淆 | 新增策略采用 `base+safety_v3` ID；界面显式标注 `V1-NAV` / `V2-PORT`；旧策略库存不变 | PASS（Godot 14/14） |
| P2 | 单条顺滑回放可能被误解为总体安全 | HUD 显示任务 ID、单场结果、总体场数/碰撞率，对碰撞/搁浅/越界添加红色事故标记 | PASS（Godot V3 验收 2/2） |

| P3 | HIL、实船接口、校准、海试、认证 | 明确列为外部阻塞项，不用模拟数据补齐 | BLOCKED（诚实保留） |
