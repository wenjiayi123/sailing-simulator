# 简历证据、面试口径与禁用表述

## 建议简历版本

**【工程2】AI智能船舶自主航行模拟器与强化学习训练平台（独立全栈自研）**

[系统演示] / [GitHub 源码]

面向无人船控制策略接入、离线回归与安全准入，独立构建“公开环境数据接入—无渲染训练—时间隔离评测—策略安全门禁—Godot 三维回放”闭环；统一建模船舶动力学、航迹跟踪、复合障碍与岸线安全包络、动态交通会遇、TCPA/闭合速度风险感知及风浪流扰动，并以标准数据契约支持 AIS、GeoJSON 与实验港区替换。

▸ **平台价值：** 构建 v1 28 维通用航行与 v2 45 维真实港口因素环境，统一连续油门/舵角与 9 离散动作，覆盖船型尺度、低阶操纵、圆形/矩形/多边形岸线危险、水深/潮位/UKC、航道、风浪流、能见度、动态会遇 TCPA/DCPA、保守 COLREG 代理、碰撞/搁浅/越界/超速/XTE/最小净距评测；集成 PPO、SAC、TD3、DQN、A2C、DDPG、TRPO 与 LOS-PID、LQR、MPC 十方法，以“证据可复现门禁 + 控制策略安全准入门禁”避免将仿真零碰撞误判为实船安全认证。

▸ **真实港口数据工程：** 流式扫描 NOAA 2025-01-01—07 七个全国 AccessAIS 原档 **47,958,624 行 / 1.335 GB**，筛选长滩港区 **85,435 条历史 AIS 运动记录、137 个 MMSI**，叠加 NOAA ENC Direct 派生的岸线/障碍/32 个水深区/12 个航道/限制区/TSS 与同期 Open-Meteo 环境输入，构造 **409 个时间隔离任务**（207/72/130 Train/Validation/Test）；船型尺寸、吃水、风浪流、能见度、潮位与速度代理字段覆盖率均为 **100%**，研究契约通过但实船控制保持 fail-closed。

▸ **十算法覆盖证据：** 七种 RL 在 v2 真实港口因素环境实际执行 **14,144 个训练步**，十方法完整完成 **720 个验证 + 1,300 个最终留出测试 rollout**；LOS-PID/LQR/MPC 在 130 场 test 的无碰撞到达率分别为 **86.9%/70.0%/73.8%**，但碰撞场景率仍为 **13.1%/18.5%/16.9%**，统一安全门禁保持 **FAIL-CLOSED**。该短预算实验只证明公开数据、十后端和现实因素闭环均可执行，不宣称七种 RL 已收敛。

▸ **可靠性指标：** 基于 Open-Meteo 长滩邻近水域 2024 年 1—4 月 **2,904 条连续小时公开风浪流数据**构造 **121 个时间隔离场景**（60/31/30 Train/Validation/Test），121/121 场景具备 5 航点、静态障碍、地形风险、动态交通船与完整环境强迫；四种 RL 实际完成 **80,480 个环境步、167 个训练 episode**，五方法完成 **155 个验证 + 150 个最终留出测试 rollout**。SAC 在 30 场测试中实现 **30/30 无碰撞到达、0 碰撞/地形碰撞**，平均/P95 最大 XTE 为 **9.98/15.13 m**、平均最小净距 **8.51 m**；但 P05 净距仅 **0.99 m**、近失场景率 **100%**，因此安全门禁拒绝放行。

▸ **工程与安全门禁：** 核心代码、公开数据、奖励/动力学配置、5 份 checkpoint、4 个模型、5 份测试回放及逐场 CSV 均纳入 SHA-256 与一致性核验，**28/28 项证据检查、150/150 逐场记录、5/5 份回放共 1,723 个采样点**全部通过；Godot 4.7 场景解析与 8 帧 headless 启动 **2/2 通过**并绑定 34 个脚本/场景源文件，前端/快捷键/主船航行回归 **36/36 通过**。当前五方法在 32 m 保守风险包络与 P05 DCPA/净距门槛下策略准入 **0/5 放行**，如实保留安全裕度缺口（公开模式数据驱动仿真，非实船海试或认证结论）。

▸ **技术栈：** Godot 4.7 / GDScript + Python / Gymnasium / Stable-Baselines3 / sb3-contrib / PyTorch + PPO / SAC / TD3 / DQN / A2C / DDPG / TRPO / LOS-PID / LQR / MPC + 28/45 维状态空间与多目标安全奖励 + NOAA AccessAIS / NOAA ENC Direct / Open-Meteo + Train/Validation/Test 时间隔离 + SHA-256 实验证据链 + GitHub Actions

## 为什么这里应写“平台价值”，而不是财务收益

项目的直接产出是仿真验证平台、控制算法闭环和可追溯实验，不具备真实港口运营对照、实船执行结果或财务核算，因此不能写“事故率降低”“燃油节省”“航时缩短”等已落地业务收益。可以在面试中表述为：

> 为无人船控制策略提供统一的数据接入、回归测试、安全准入和三维复盘环境，降低算法接入与重复验证成本，并在实船测试前暴露碰撞、近失、净距和航迹偏差风险。

这是平台业务价值，不是已实现的财务 KPI。

## 关键指标解释

- **2,904 条**：2024-01-01 至 2024-04-30 的连续小时公开再分析/模式环境输入；只提供离线环境强迫，不是实测船舶操纵轨迹。
- **121 场**：公开强迫按日聚合后，与 3 类项目原生路线/障碍模板组合；路线和危险物布局不冒充官方电子海图。
- **80,480 步**：PPO 因 rollout horizon 实际完成 20,480 步，SAC/TD3/DQN 各 20,000 步；LOS-PID 是无训练控制基线。
- **150 个测试 rollout**：5 种方法分别覆盖 30 个从未参与训练或验证的 4 月场景。
- **30/30 无碰撞到达**：SAC 在固定测试协议下到达目标且碰撞/地形碰撞为 0；其近失场景率仍为 100%，不等于避碰认证或任意海域安全。
- **9.98/15.13 m**：SAC 每场最大 XTE 的均值/P95，不是 GNSS 或传感器定位精度。
- **8.51/0.99 m**：SAC 每场最小净距的均值/P05；尾部净距风险是其未通过准入的重要原因。
- **0/5 准入**：32 m 风险包络是保守离线门槛；五方法均出现包络侵入，因此平台拒绝放行。它证明安全门禁不会用零碰撞掩盖风险，不代表算法研究已经收敛完成。
- 当前只报告一个固定随机种子的基准；可复现不等于多随机种子统计显著性。
- **47,958,624 / 85,435**：前者是七个 NOAA 全国日档实际扫描行数，后者是长滩边界、时间和运动质量筛选后保留的 AIS 行数；原始压缩档不提交 Git，URL、字节数和 SHA-256 均保存在来源清单。
- **409 个 v2 任务**：207 train、72 validation、130 test，按来源日期隔离；任务是历史航迹切片，不是 409 次实船自动驾驶试验。
- **14,144 步 / 1,300 个 v2 test rollout**：七种 RL 的短预算执行覆盖与十方法全 test 覆盖；用途是验证后端和模拟器因素，不用于声称 RL 收敛或控制算法优越性。

## 面试可核验入口

```bash
make test
make benchmark-verify
make reliability-audit
make release-check
make benchmark-deep-verify
make godot-acceptance GODOT=/path/to/Godot
```

- `reports/simulator_reliability_audit_v3.json`：绑定当前 Godot 源码的场景覆盖、执行规模、五方法指标、回放一致性、双门禁及声明边界；V1 历史审计原样保留。
- `reports/navigation_benchmark_v1.json`：软件版本、数据切分、训练摘要、逐方法聚合指标和证据哈希。
- `reports/artifacts/navigation_benchmark_v1/*/*_test_episodes.csv`：150 条逐场测试结果。
- `reports/artifacts/navigation_benchmark_v1/*/checkpoint.json`：算法、训练步数、数据/实验指纹和模型路径。
- `reports/godot_acceptance_v3.json`：当前 Godot 版本、解析/启动结果及源文件树指纹；V1 回执作为历史快照保留。
- `data/public/*.provenance.json`：公开输入请求 URL、许可、抓取时间和 CSV SHA-256。
- `reports/port_ops_benchmark_v2.json`：45 维、十方法、409 个真实 AIS 航迹任务的覆盖性运行报告。
- `reports/port_dataset_contract_v2.json`：现实因素覆盖、数据量、字段完整率与实船 fail-closed 状态。
- `reports/godot_ui_navigation_smoke_v1.json`：按钮/快捷键/十算法清单及主船人工与后端控制回归。

## 禁止直接使用的表述

- “实船验证”“真实港口部署”“生产级自主航行”；
- “100% 安全完成”“避碰成功率 100%”“通过 COLREGs/船级社认证”；
- “使用实时 AIS 训练/已接入实时 VTS”——v2 使用 NOAA 历史 AIS，当前没有实时港口遥测；
- “航行成本/油耗/事故率降低 X%”——当前没有真实运营对照；
- “训练 121 个场景”——其中只有 60 个 train 场景，31 个 validation 场景、30 个 final test 场景。
