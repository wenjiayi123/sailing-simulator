# 路线图

路线图表达方向，不构成发布时间承诺。优先级会根据安全、许可、复现价值和维护成本调整。

## 近期：0.1.x

- 为五种基线提供统一的多随机种子 benchmark 报告命令。
- 增加 Linux 与 Windows 的 Godot 解析检查说明。
- 扩展数据契约边界测试、异常输入提示和小型示例配置。
- 增强无障碍、分辨率自适应和英文 UI 覆盖。

## 中期：0.2

- 定义可插拔船舶动力学接口，并提供经过参数记录的高保真模型示例。
- 增加多船会遇、COLREG 研究指标和确定性场景生成器。
- 为合法可再分发的公开港口数据提供端到端转换示例。
- 输出版本化 benchmark 清单、聚合指标与失败案例索引。

## 长期研究方向

- 仿真到现实差距分析与域随机化评估。
- 多智能体协同与通信失效场景。
- 人在回路的教员标注、策略审查和安全接管。
- 与标准化水动力、传感器和硬件在环平台的适配层。

## 明确不承诺

- 不把项目描述为经认证的航海系统。
- 不在没有来源、许可和精度说明时内置真实港口或船舶数据。
- 不以动画、演示轨迹或单次短训练替代可复现实验结果。

欢迎通过 Feature Request 提议可验证的里程碑；涉及大范围变更时，请先说明验收标准和兼容性影响。
