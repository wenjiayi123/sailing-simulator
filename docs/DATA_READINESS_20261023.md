## 来源与后续替换

各系统保留自己的数据口径：小懿使用已登记的 NOAA LA/LB AIS 校准包和 UCI 能耗公开样例；能碳使用项目登记的洛杉矶港/EIA/eGRID 锚点；马六甲使用 MPA、Open-Meteo/ERA5、公开 AIS 研究参考及工程模型。UCI 样例不是港口设备实绩，跨港研究参考也不是马六甲现场统计。具体来源、时间、质量与推导说明以原生接口和导出文件为准。

| 系统 | 原生快照 / 合同 | 替换方式 |
| --- | --- | --- |
| 小懿 | `/api/runtime/snapshot`；`/api/port-simulator/contract` | 按既有 `docs/PORT_OPERATIONS_DATA_ADAPTER.md` 配置 live 网关、允许主机和只读令牌；适配器输出 `port-ops.v1` / `port-realtime.v1`，保留现场质量准入。 |
| 能碳 | `/api/runtime/snapshot`；`/api/runtime/contract` | EMS/BMS/BA/TOS/表计适配器输出相同字段和 `telemetry-field.v1` 元数据；不得仅替换 value 丢失时间、单位、质量和来源。 |
| 马六甲 | `/api/operations/snapshot`；`/api/operations/contracts/telemetry` | 通过既有 `/api/operator-integration/contract` 接入现场六源，维持签名、时序、单位和质量合同；禁止用另一港口的遥测补上海现场指标。 |
| 航行 | `user://port_profile.json`；既有 port dataset 合同 | 港区几何按 `ship_port_profile_v1`；研究任务保留来源 URL、SHA256 和时间隔离；水文/传感器/船岸桥及算法继续用原生适配与验收。 |
| PortAI | 港口 Web `/api/public-port-demo/workspace` | 客户端不维护另一套 KPI，随共享接口供数；生产授权与演示展示分别验收。 |

三个网页的导出格式为 `system-data-readiness-review.v1`，原始对象在 `native_snapshot` 与 `native_contract`。该文件是审阅包，不应直接当作生产网关响应；实际适配器需要输出对应系统的原生合同。

现场 AIS 身份/ETA、TOS 任务回执、结算计量、M&V、碳资产证明、海图更新、实船校准、控制联锁等仍保留待接入或待验收。演示数据齐备不授予设备控制权。

## 性能与失败处理

- 新增网页入口无启动请求、定时轮询和动画；点击后才并行读取快照与合同，12 秒超时。关闭或刷新会取消旧请求，晚到响应不能覆盖新结果。
- 源失败时清空本次指标并禁用导出，保留刷新恢复；已通过隔离的 HTTP 503 → 恢复浏览器检查。
- 客户端数据卡按需加载，不新增轮询；失败清空旧数据，0 是有效值，缺值显示破折号。
- 航行报告只在点击时读取并验证来源；报告缺失或来源变化时清空内容并禁用导出，原策略不受该报告授权。
- 现有能碳与马六甲构建仍有大于 500 kB 的分包提示；此次没有新增三维引擎。马六甲卫星地图仍为已有按需加载模块。本轮未进行长期帧率压力测试。
