# 长滩港研究数据卡 / Data card

## 数据组成

| 层 | 内容 | 当前语义 |
|---|---|---|
| AIS | NOAA AccessAIS 2025-01-01 至 2025-01-07 历史档 | 观测到的历史船位/航迹；不是实时交通 |
| ENC 派生层 | NOAA ENC Direct 岸线、障碍、水深、航道、限制区、TSS | 研究 GIS；不是船载认证海图 |
| 海况 | Open-Meteo 同期风、浪、流、能见度、模式海平面 | 公开数值产品；不是船载传感器 |
| 动力学与动作 | 项目船型参数、油门/舵角和仿真状态转移 | 反事实模拟；不是实船执行记录 |

数据包包含 409 个真实航迹任务，按时间隔离为 207 train、72 validation、130 test；任务内记录船型尺度、吃水、海况、动态交通与导航上下文。原始来源 URL、检索时间、文件哈希、许可证与转换说明位于 `data/public/` 和 `docs/DATA_SOURCES.md`。

## 质量控制

- AIS 航次不跨 split；实验和数据均有 SHA-256 指纹。
- 港口合同核验必填字段、坐标、本地航线、动态目标、深度/UKC 与 `live_control_ready=false`。
- prepared 报告在 test 前冻结模型、配置、源码与 validation 产物。
- 缺深度、来源、时效或授权时采取 fail-closed，不用生成值填充生产字段。

## 局限

AIS 存在缺报、误报、采样不均和身份/船型字段缺失；公开海况的空间分辨率不等于港池实测；ENC 派生层不保证在航更新。数据未覆盖拖轮/引航指令、泊位计划、VTS 意图、雷达原始回波、执行器状态、人工接管和事故真值，不能用于生产控制认证。
