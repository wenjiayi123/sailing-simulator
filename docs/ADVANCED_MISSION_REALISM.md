# 高级任务现实性与顶级模拟器对标

本轮把五个高级任务从“地图和结束门槛”推进为可运行的任务现实性闭环。目标是贴近高质量全任务驾驶台训练的软件能力，不把通用模型描述成指定船舶或获认证模拟器。

## 已进入运行时的能力

- 五个任务分别配置风、浪、流、潮位、能见度、时间、水深、船舶吃水和任务能力项；所有 7 个场景进入时确定性恢复为零雾晴天。高级任务保留各自的风、浪、流和潮位基线，但限制能见度与任务时刻改为显式天气训练项，不在进入场景时暗中叠加薄雾；之后仍可由天气面板调整。
- 能见度按气象光学距离使用 `3.912 / visibility_m` 换算雾消光密度，避免把千米数值直接当作引擎雾密度而遮掉四周地平线；真实渲染像素回归会拒绝纯色晴空画面。
- 原有三自由度船舶动力学新增有界浅水效应：水深傅汝德数、动态下沉量、富余水深和额外纵向阻力。
- 两个狭水道任务新增有界岸壁效应：按船位、船宽、可航半宽、船速和岸距计算侧向吸力与艏摇力矩。该模型是研究代理，并非计算流体力学或实船标定模型。
- 新增持续机械故障：左舷推进损失、右舷推进损失和操舵偏差。注入必须带操作者身份，只影响本船，持续到明确恢复，并生成顺序回执。
- 每项任务要求雷达与自动雷达标绘仪、电子海图显示与信息系统、综合驾驶信息、全球海上遇险与安全系统训练器、教员控制和记录复盘六个软件域可用，才能通过任务前检查。
- 运行时持续采样最低富余水深、最低岸距、最大下沉量、水深傅汝德数、任务门槛、故障和操作者行动；复盘按安全 50 分、任务 30 分、程序 20 分生成 100 分结构化报告。

在 `N` 航行任务面板中，依次使用“应用任务”“任务前检查”“记录关键操船”“导出结构化复盘”。任务前检查和复盘不会自动替操作者确认。

## 五个任务的现实训练重点

1. 自动靠泊：到港前简报、减速计划、平行靠拢、首向、横移和无接触停车。
2. 自动离泊：离泊简报、全方位瞭望、倒车控制、回旋水域控制、防波堤净距和出口速度。
3. 狭水道对遇：第 9/14 条识别、右侧航行、及早明显向右行动、安全航速、会遇距离和恢复原航向。
4. 右舷交叉：第 15/16 条识别、及早大幅度让路、从他船船尾通过、持续监视和恢复航线。
5. 狭水道追越：第 9/13 条识别、追越协议回执、岸距、追越会遇距离、并航时间和安全回归航道。

## 对标依据与结论边界

国际海事组织 STCW 模拟器条款要求实时运行环境、适当驾驶台设备与通信、昼夜和可变能见度、风潮流和船间作用，以及限制水域中的浅水与岸壁效应。DNV-ST-0033 的现行认证路径强调与训练目标相匹配的物理和行为真实度。K-Sim Navigation 与 Wärtsilä NTPRO 的公开能力还包括真实/仿真驾驶台设备、教员控制、多站协同和专用硬件。

当前软件已覆盖这些基准中可在本地可信实现的任务链，但仍不是顶级产品的等价替代。指定船舶标定、官方在航海图、物理多通道 360° 驾驶台、真实控制器硬件在环、拖轮/缆绳/碰垫高保真模型、认证教员课程、独立型式认可和海试必须由外部证据完成。对应状态和所需证据见 `data/verification/advanced_mission_top_tier_mapping_v1.json`。
