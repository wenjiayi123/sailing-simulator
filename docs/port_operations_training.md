# 港内作业程序训练

更新时间：2026-08-28

## 程序范围

- 靠泊：船长/引航员信息交换、训练泊位边界、拖轮与应急方案、3 节进靠门槛、平行趋势、全船系牢回报。
- 离泊：交通窗口、训练几何、设备就绪、解缆与拖轮指令、回弹区、5 节离泊门槛。
- 拖轮协同：配置、呼号/频道、标准推拉停指令、闭环复诵、连接与受力监控、释放。
- 锚泊：锚地评估、训练水深、备锚、2 节抛锚门槛、出链、锚位警戒与走锚趋势。
- 系泊站：人员设备、回弹危险区、缆绳顺序、模拟受力、负荷平衡、全船系牢回报。
- 侧推器：配置与限制核对、零输出检查、标准指令、告警和归零；只做程序干运行。

每一步都要求界面提交显式证据；需要时额外要求闭环复诵、训练几何确认、侧推器干运行确认和实时航速门槛。拒绝和成功都保留唯一回执。

## 真实性边界

- 默认资料是合成训练剖面，泊位几何、官方水深、引航/拖轮地方规则和船型侧推器配置均未现场核验。
- 系统不施加拖轮力、锚链力、缆绳力或侧推器力，不改变船舶运动模型和策略。
- 当前能力用于程序、团队沟通和安全门槛训练；不声称具备全任务靠离泊动力学或现场作业权限。
