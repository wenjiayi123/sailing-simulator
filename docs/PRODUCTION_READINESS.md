# 生产就绪门禁 / Production readiness

当前结论：**离线研究与可复现实验可用；实船/港口生产控制未就绪，保持 fail-closed。**

| 门禁 | 当前证据 | 状态 | 转为通过所需外部证据 |
|---|---|---:|---|
| 数据来源与时间切分 | 公开 AIS/ENC/海况来源、哈希、train/validation/test | PASS（离线） | 无 |
| 基础策略可复核 | V1/V2 checkpoint、模型、指标、失败记录 | PASS（离线） | 无 |
| 运行时软件安全层 | V3 候选动作前瞻、干预、fail-closed、独立 test | 以 V3 报告为准 | 不得替代硬件联锁 |
| 视觉资产再分发 | 若干角色/纹理来源未确认 | BLOCKED（全视觉包） | 逐项许可或替换；研究核心包可独立发布 |
| 实时 AIS/VTS/TOS | 当前仅历史 AIS，无生产接口 | BLOCKED | 授权 API、时效/SLA、身份映射、断链策略、审计 |
| 官方航海产品 | 当前为 NOAA ENC 派生研究数据 | BLOCKED | 适航官方产品、更新服务、版本/许可/覆盖验证 |
| 船型与执行器标定 | 通用 3-DOF 模型、执行器动态、数值/阻尼/对称验收和 Nomoto 辨识接口 | PASS（软件模型）/ BLOCKED（指定船舶） | 指定船舶 zig-zag、回转圈、停船、装载工况辨识与误差包络 |
| HIL/实时性 | UDP/NMEA 软件回环、完整性/顺序/时效/限幅门禁、watchdog、故障注入和回执链 | PASS（软件回环）/ BLOCKED（物理 HIL） | 目标控制器、真实 I/O/植物模拟器、独立急停、WCET、时钟同步和见证测试 |
| 人工接管与回滚 | 模拟器可停止回放 | BLOCKED | 双通道急停、手动优先权、状态机、回滚演练、值班程序 |
| 法规/船级/海试 | COLREG 规则追踪正反场景 + 分阶段海试协议、遥测判据和证据完整性拒绝门禁 | PASS（软件规则/协议）/ BLOCKED（认证与实船） | 多船/地方规则验证、风险评估、主管机关/船级流程、物理 HIL、许可、见证、原始日志和签字海试 |

详细软件证据和外部门禁见 [航海保障指南](MARITIME_ASSURANCE_GUIDE.md) 与 [V1 报告](../reports/maritime_assurance_v1.md)。生产适配器不得仅通过修改一个布尔值启用。必须提交可复核的接口合同、校准报告、物理 HIL、影子运行、接管/回滚、独立验收和授权记录，并新增版本化证据；不得覆盖当前离线报告。
