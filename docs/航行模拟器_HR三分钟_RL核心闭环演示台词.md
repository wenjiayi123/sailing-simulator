# 航行模拟器——HR 三分钟 RL 核心闭环演示台词

适用方式：录制时只念“口播”部分，括号内是同步操作，不需要念。

建议时长：3 分 10 秒至 3 分 40 秒。

演示主线：先展示训练后自动避障的结果，再解释数据训练与参数，最后再用新生成的 checkpoint 回放，形成完整闭环。

## 录制前准备（不念）

1. 先运行项目，按 `C` 打开训练页。
2. 数据选“`v1 动态避障基准 / 28维`”，策略选“`V1-NAV SAC｜原训练策略｜冻结证据保留`”。这是 20,000 step 训练并已完成 30 场独立 test 的主演示策略。
3. 点击“运行测试集并渲染”，确认 HUD 显示任务 ID、本场结果和总体场次；不在录制前临时覆盖这份冻结产物。
4. 关闭并重新运行项目，让画面回到干净的初始状态。
5. Mac 按 `Command + Shift + 5`，选择“录制所选部分”，选中 Godot 运行窗口，在“选项”中打开麦克风。
6. 正式录制中，策略回放时不要按方向键；小船已经由外部策略的油门和舵角指令接管。
7. 为了在视频内现场跑完一次训练，第二段使用 `episodes=20`、`steps=100`、`agents=1`。这只是短流程验证；开场回放使用的是提前准备的 200 回合策略。

---

## 00:00—00:15 直接展示 RL 结果

（操作：开始录制，让航行主画面保持 1 秒。按键盘 `C`，在打开的“RL 船队控制”训练页中，鼠标点击“运行测试集并渲染”。点击后立即把鼠标移到画面边缘。）

口播：

> 我先直接展示核心结果。现在加载训练后冻结 checkpoint 及其独立 test 记录动作，小船从人工操船切换到策略轨迹回放。这不是手工画的动画；画面中的油门、舵角、动态障碍和到达结果来自已封存的测试 rollout。

## 00:15—00:45 展示自动转舵、避障和回线

（操作：不要操作方向键。让小船自动接近评估障碍，画面上方保持显示 `POLICY EVALUATION`。小船开始转向时，可轻按 `A` 或 `D` 一下微调镜头，但不要大幅旋转。）

口播：

> 我关注的不只是“船绕过去了”，还包括连续转舵、最小安全净距和避障后回归航线。顶部实时记录 collision、minimum clearance 和 XTE，把安全与航线保持变成可量化结果。

## 00:45—01:15 说出对国际港航的理解

（操作：小船继续自动航行。如果已到达目标，让顶部 `SUCCESS / GOAL REACHED` 和完整评估指标留在画面上，不要马上切换界面。）

口播：

> 我对港口数字孪生的理解是，价值不在于把港区画得多像，而在于真实执行前能否调变量、做 what-if 和量化风险。新加坡 MPA 的 Maritime Digital Twin 用实时与历史数据、仿真和建模来验证 what-if 场景；NGVTMS 用数据分析识别交通热点，并用高级算法与机器学习预测碰撞。我把这个范式缩小成“快照、训练、安全约束、执行、评估”闭环。

## 01:15—01:40 展示 RL 参数与安全目标

（操作：按 `C` 打开“RL 船队控制”训练页。鼠标点击“算法/环境设置”，先停在参数总览上，然后轻轻向下滚动，让 `SAFETY`、`ENVIRONMENT` 和 `RANDOMIZATION` 分组出现。不要在录制中临时修改参数。）

口播：

> reward 不是单一的“越快到达越好”。它同时奖励航线推进、航向贴合和经济航速，惩罚碰撞、越界和过大舵角，并显式设置最小安全距离。港口任务不能只看到达率，还必须看安全与操纵稳定性。

## 01:40—02:15 现场展示无渲染数据训练

（操作：鼠标点击参数窗右上角“关闭”。在训练页选择 `PPO`；训练轮数输入 `20`；`steps` 输入 `100`；并行环境输入 `1`；评估回合输入 `1`。鼠标点击“启动训练”。）

口播：

> 现在现场跑一次短训练。Godot 先导出船舶动力学、航点、障碍物和边界快照，再暂停世界物理与 3D 渲染，把资源用于 Python 后台采样和策略更新。画面变成纯数据面板，是有意的训练与演示解耦，不是卡顿。

（操作：训练面板出现后，鼠标移到边缘。画面停留在进度条、阶段列表和指标区。等待顶部变为 `POLICY READY // 无渲染训练完成`。）

口播：

> episode、data step、reward、success rate 和 collision rate 都来自实际训练进程。完成后会一起产生指标、checkpoint 和评估轨迹。

## 02:15—02:45 把新 checkpoint 重新接入小船

（操作：当面板显示 `POLICY READY` 后，鼠标点击右上角“播放策略”。画面回到 3D 航行视图后，不要操作方向键。）

口播：

> 现在恢复 3D 场景和物理，播放本次新生成 checkpoint 的评估轨迹。同一份输出文件把“快照—训练—checkpoint—执行—评估”连成了闭环。只有明确选择 `+SAFETY-V3` 时，才可以说播放的是外挂安全监督组合策略。

口播：

> 当前原型使用 Stable-Baselines3 运行 PPO、SAC、TD3、DQN 四种强化学习基线，并提供 LOS-PID 控制理论基线；训练支持多个无渲染数值环境，检查点和独立测试结果可追溯。

## 02:45—03:15 强视觉收尾与个人判断

（操作：等小船完成回放，让 `SUCCESS / GOAL REACHED`、collision、minimum clearance、max XTE 和 elapsed 停留 2 秒。然后按 `O` 打开“教员控制台”，鼠标点击“简易港口”，再点击“黄昏”；等画面切换后点击右上角“收起”。轻按 `A` 或 `D` 缓慢转动镜头，让港口设施、水面、小船和 HUD 同时入画。）

口播：

> 这不只是一条会开的船。我的判断是，港口决策系统不能只有模型和漂亮的 3D 画面；它还要让人看到环境变量、策略来源、安全约束和执行结果。所以我把航行可视化、RL 训练与安全评估做成了同一个可复盘闭环。

（操作：镜头停在港口黄昏全景和 HUD 上 3 秒，结束录制。）

## HR 只看 60 秒时的备用剪辑

保留正片的 `00:00—01:15`：

1. 点击“运行测试集并渲染”。
2. 展示小船自动转舵、避障、回线和到达。
3. 保留“数字孪生不是把港区画得多像”和 MPA / NGVTMS 的口播。
4. 在 `SUCCESS / GOAL REACHED` 指标画面结束。

这 60 秒已经能让观众看到“视觉结果 + RL 接管 + 港航理解 + 可量化安全指标”四个核心信号。

## 用词边界

- 可以说：“参考 Ray/RLlib 的并行评估、指标、checkpoint 和可恢复实验思路。”
- 不要说：“这个项目已经使用 RLlib 进行分布式训练。”当前代码不支持这个表述。
- 选择原 V1/V2 策略时可以说：“这是冻结 test rollout 中记录的策略动作回放。”
- 只有选择 `V2-PORT ... +SAFETY-V3` 时可以说：“这是原策略外挂运行时安全监督的组合策略。”
- 不要把一条顺滑回放说成全部 test 场景都安全；HUD 已同时标注“本场结果”和“总体场次/碰撞率”。
