# 演示引导栏

右侧“演示开始”或 F8 打开引导。共 38 步（含已训练场景证据清单），包含主驾驶场景、算法与证据、静态/动态回放、七个场景策略、业务面板及结束页。

首次点击主按钮执行当前步骤；之后每次点击直接进入并执行下一步，不再需要第二次点击。上一步和步骤下拉框同样直接执行目标步骤。失败时停留本步，可重试；不会把失败记作完成。

“N 场景”区一次点击即可应用任务、重定位并启动匹配的 SAC，不必回到 N 面板操作。快速切换会取消旧请求。离开场景策略步骤时，先停止策略、恢复原任务及选项；关闭或折叠引导仅改变显示。

独立红色“手动停止策略 / 回放”在等待、折叠和关闭状态均可使用。停止会取消待启动请求，不推进步骤；原生启用过程超过 15 秒则取消并提示重试。

仅启动时的开放水域场景改用现有港口岸桥背景；港口引航、靠离泊、对遇、交叉和追越保持各自原有背景。水面、天气、岸线实体和碰撞几何仍使用对应场景配置。

狭水道对遇从靠近中线的右侧位置起航，展示提前右转、保持右侧、会船及恢复航线。引导实时显示会遇阶段、预测 CPA/TCPA 和实际最小船间距；显示内容来自当前船舶状态。

追越的前船起点调整至 z=-115 米，使实际速差能在地图范围内完成追越。前船由独立 SAC 保持航道，本船 SAC 输出全部油门与转向。演示预设包含模拟追越协商；从 N 面板可点击“确认模拟协议并启用 SAC”，一次完成模拟协议回执与启动，也可先手动勾选协议。确认后旧的协议错误立即清除；撤销协议会取消待启动请求或停止当前策略。该回执没有真实 VHF 授权含义。

训练与准入记录在 `data/rl/mission_rl_catalog_v1.json`。本轮对遇进行了 SAC 微调，其他场景复用冻结网络并重新验证；原模型和历史失败记录保留。任何来源、合同、模型指纹或原生验证失败仍会阻止接管。

回归入口：

```bash
.venv/bin/python -m unittest tests.test_mission_rl -v
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --fixed-fps 60 --script tools/godot_demo_guide_regression.gd
```

回归脚本检查当前步骤清单的按钮信号与状态推进、场景切换取消、手动停止、模拟协议及四面背景，并恢复演示进度文件。画面观感、鼠标命中和完整讲解由用户手动验收。
