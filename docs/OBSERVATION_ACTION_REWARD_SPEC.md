# 观测、动作与奖励规格

本文档对应当前冻结的长滩港 V2 实验配置 `data/rl/long_beach_ais_port_ops_experiment_v2.json`。代码实现以 `tools/ship_rl/environment.py` 和 `tools/ship_rl/port_ops_environment.py` 为准。

## 动作空间

除 DQN 外，所有 RL 策略和控制基线最终输出二维连续指令：

`action = [throttle_command, rudder_command]`

- `throttle_command ∈ [-1, 1]`：全速倒车至全速前进。
- `rudder_command ∈ [-1, 1]`：两侧满舵之间的连续舵令。

指令经油门响应、舵机响应、加减速、低速舵效、倒车舵效、风流浪扰动后才改变速度、航向和位置，不直接写入速度或航向。DQN 使用九个离散油门/舵令组合，即 `{-1, 0, 1} × {-1, 0, 1}`。

## 观测空间

基础航行观测为 28 维：目标距离、航向误差正余弦、速度、当前油门和舵、横向偏差、最近障碍净距和方位、流/风/浪状态、航点进度、闭合速度、TCPA、DCPA、动态目标标志、边界净距及前/左/右扇区净距。

港口环境叠加 17 维，合计 45 维：能见度、潮位、水深、龙骨下富余水深（UKC）、是否在航道内、航道边缘余量、限速余量、船长、吃水、会遇方位正余弦、迎遇/右舷交叉/左舷交叉/追越 one-hot、让路责任与交通密度。

## V2 奖励函数

单步基础奖励为：

```text
r = 2.8 * (previous_target_distance - target_distance)
  + 1.4 * 0.02 * cos(abs(heading_error))
  + 0.5 * 0.01 * min(speed_ratio, 1)
  - 0.35 * 0.01 * abs(rudder)
  - 0.08 * min(abs(cross_track_error) / 80m, 3)
  - 0.06 * sum(abs(action - previous_action))
  - 0.002
```

安全与运行约束叠加如下：

- 净距低于 80m：`-1.6 * (80m - clearance) / 80m`。
- 动态目标 `TCPA < 900s` 且 `DCPA < 80m`：`-2.4 * DCPA_risk * TCPA_urgency`。
- 普通碰撞事件：`-72`；岸线/地形/搁浅碰撞：`-96`；越界：`-64`。
- UKC 低于 1m：按缺口比例乘 `3.0` 扣分；UKC 小于等于零触发搁浅。
- 超速：超出航区限速的相对比例乘 `1.0` 扣分。
- 离开强制航道：每步 `-1.8`。
- 已判定为让路船且存在预测冲突时，未对迎遇/右舷交叉/追越采取当前代理规则认可的动作：每步 `-2.2`。
- 通过中间航点：`+3`；到达最终航点：`+12`。

`near_miss` 作为评估事件单独计数，不重复增加一项固定惩罚；其风险已由净距和 TCPA/DCPA 密集惩罚表达。

## 环境与证据边界

- 航线和动态交通来自历史 AIS 任务；岸线、浅水、航道、限制区和 TSS 来自 NOAA ENC Direct 派生 GIS；船长、船宽和吃水由数据契约携带。
- 历史 AIS 交通不会对智能体动作作出反应；智能体航行是反事实仿真。
- COLREG 是可审计的粗粒度代理，不是完整法规或认证实现。ENC Direct 派生数据不是认证航海产品。
- 当前系统不具备实时传感器、VTS/TOS 调度权、硬件联锁、HIL、海试或实船控制授权。

## 评估要求

奖励是训练信号，不是安全结论。任何“奖励已优化”的结论至少需要：多随机种子、长预算训练、独立 validation/test、奖励分项累计尺度报告、奖励消融，以及碰撞、搁浅、超速、航道和 COLREG 代理约束的独立门槛。
