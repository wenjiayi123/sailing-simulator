# 港口生产联动功能层

## 结论

最后一项生产联动缺口已在“模拟器功能”层完成：船舶交通服务（VTS）、码头操作系统（TOS）、引航、拖轮、泊位资源和官方航海通告具备统一但权威范围隔离的适配器、时效/单位/字段门禁、断链降级、人工确认协调、调度回执和防篡改审计链。

当前证据来自签名离线夹具，所有真实站点声明仍为 `false`。本层不连接真实端点、不外发调度、不把消息映射到执行器，也不修改船舶运动模型、观测/动作/奖励或十套既有策略。

## 六类连接器

| 连接器 | 允许进入模拟器的权威范围 | 主要失效门禁 |
|---|---|---|
| 船舶交通服务 | 交通态势与已授权航行服务提示 | 身份、HMAC、哈希、序号、防重放、时效、字段/单位 |
| 码头操作系统 | 泊位计划与作业窗口 | 同上；断链后撤销来源权威 |
| 引航 | 引航订单与协调回执 | 白名单请求、操作员身份、人工确认、回执 |
| 拖轮 | 拖轮订单与协调回执 | 白名单请求、操作员身份、人工确认、回执 |
| 泊位资源 | 泊位可用性、限制与资源状态 | 必填字段、单位、时效、来源隔离 |
| 官方航海通告 | 通告范围、有效期和状态 | 发布时间、到期时间、未来/过期拒绝 |

每个训练适配器使用独立 HMAC 密钥；载荷 SHA-256、唯一快照 ID、单调序号和时间窗口共同防止伪造、重放、乱序和过期数据进入权威态势。审计只保留摘要、载荷哈希、来源链和请求/回执状态，不持久化业务载荷正文。

## 降级与协调边界

- 连接断开或超过时效窗口后立即撤销该来源的权威标志，并进入显式降级状态；恢复连接不自动恢复旧数据。
- 引航/拖轮协调必须满足请求类型白名单、操作员身份和人工确认；当前只进入 `QUEUED_REHEARSAL`，`external_dispatch_performed=false`。
- 回执绑定请求 ID，加入哈希审计链；未知请求和重复/篡改回执被拒绝。
- 本层只向强化学习环境提供经过门禁的上下文或“不可用”状态，不直接改变控制命令。

## 真实站点准入

模板 `data/verification/port_production_site_acceptance_manifest.template.json` 默认拒绝。生产准入至少需要：六方书面接口授权、字段/单位/坐标/时间语义与权威优先级、服务级别协议和时钟/时效/断链测试、证书与密钥轮换、网络分区与不可变审计、至少 30 天且 1,000 场影子运行、零关键偏差、回滚演练、操作员验收，以及港口/VTS/TOS/引航/拖轮/船旗国或船级社和法律责任批准。

布尔值不能替代逐文件 SHA-256 证据；材料齐全后也仅进入独立站点评审，模拟器不会自行授予生产权限。
