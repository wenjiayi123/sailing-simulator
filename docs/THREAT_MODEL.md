# 威胁模型 / Threat model

## 资产与信任边界

| 资产 | 可信来源 | 主要威胁 | 当前控制 |
|---|---|---|---|
| 训练模型与 checkpoint | 仓库冻结 V1/V2 产物 | 恶意反序列化、模型替换 | SHA-256 清单；V3 启动前逐模型核验；不加载外部无哈希模型 |
| AIS/ENC/海况数据 | 已记录 URL、时间、许可和原始哈希的公开数据 | 投毒、时效误用、切分泄漏 | 数据契约、时间切分、来源清单、实验指纹、test 后置访问 |
| Python 训练/评估进程 | 固定本地入口与锁定依赖 | 参数注入、任意路径、依赖供应链 | 参数数组调用、不拼 shell、固定入口、依赖审查、CodeQL、SBOM |
| Godot 回放 | 已冻结 test 轨迹 | 用预制动画冒充策略、路径穿越 | 格式/哈希/数据 split 校验；失败轨迹不改写；只从允许路径读取 |
| 航行控制权 | 仅模拟器 | 把离线动作误接实船 | `live_control_ready=false`、`deployment_authority=false`、无实船适配器 |
| 发布资产 | 代码、数据、图片、纹理 | 许可不清导致错误再分发 | 全视觉包阻断；研究核心包排除未核验视觉资产 |

## 主要攻击路径与控制

1. **恶意模型文件执行代码。** SB3/Cloudpickle 不是安全交换格式。系统只允许加载证据清单中哈希一致的模型；下载或用户目录中的模型默认不可信。
2. **数据投毒或 test 泄漏。** 训练只读 train，选型只读 validation；V3 先冻结监督配置、源码和基础模型哈希，再访问 test。任何核心变化使报告校验失败。
3. **回放伪造。** Godot 只展示评估产生的带 split、策略、checkpoint 和数据指纹的轨迹。回放不是实时控制，失败/碰撞不可被 UI 改成成功。
4. **跨进程命令注入。** Godot 使用 `OS.create_process(executable, arguments)` 参数数组启动固定 Python 文件，不把用户文本拼接为 shell 命令。
5. **拒绝服务。** 数据包、episode、步数和并行环境均有显式预算；模型预测监督器有固定候选数、预测步长和决策周期，并报告延迟。
6. **错误上线。** 公开历史 AIS、ENC 派生 GIS、模式海况和仿真动力学不构成在线态势。没有实时适配、标定、HIL、海试、人工接管和主管机关批准时，生产门禁保持关闭。

## 明确不在当前保证范围

本项目未证明网络隔离、船桥系统加固、实时操作系统确定性、传感器抗欺骗、GNSS/雷达/AIS 冗余、执行器联锁、海事网络认证、COLREG 合规证明或船级社认可。上述内容是实船工程，不得由离线基准推断。
