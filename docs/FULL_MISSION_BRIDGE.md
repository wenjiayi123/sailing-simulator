# 全任务软件船桥

更新时间：2026-08-29

## 面向强化学习模拟的任务链

本模块把既有功能组合成一个完整的软件训练船桥，同时保留每个子系统的独立面板和证据：

- 雷达与自动雷达标绘仪：场景驱动量测、增益/量程/杂波、目标捕获、最近会遇距离、到达最近会遇点时间及故障模型。
- 电子海图显示与信息系统：航线、安全等深线、危险物、报警和确认；当前不是官方在航海图产品。
- 综合驾驶信息：艏向、航向、航速、舵角、车钟、漂角、横向偏差和传感器有效性。
- 全球海上遇险与安全系统/甚高频/数字选择性呼叫：16/70 频道守听，遇险报警双步骤保护，紧急/安全/常规呼叫，话音跟进、确认和取消。
- 操纵台：通过已有执行控制层完成仿真武装、自动舵目标艏向/速度、推进限幅/反馈、人工立即接管和急停。
- 多学员：九类岗位、闭环复诵、质疑响应、态势简报和本机 UDP 会话。
- 软件全向视景：八个 45° 扇区，形成 360° 镜头扫描回执；该功能只改变镜头，不改变船舶状态转移。
- 教员与复盘：确定性演练时间线、设备故障、唯一回执、报告和复盘导出。
- 高级任务现实性：五个专项任务接入确定性风浪流潮与能见度、富余水深与动态下沉量、狭水道岸壁效应、持续推进/操舵故障、任务前检查和 100 分结构化复盘。

在系统总览点击“全任务软件船桥”，或按 `F12` 打开。面板可跳转到各专业子台。

## 通信安全边界

- 所有通信均使用 `TRAINING-999000001` 训练身份。
- 遇险报警必须先准备，再由同一操作员完成至少三秒确认；直接绕过会被拒绝。
- 无无线电射频输出、无天线、无海岸电台连接、无真实海上移动业务标识。
- 通信记录带顺序号和 SHA-256 前向回执链，但它不是认可设备日志。

## 当前没有宣称的能力

- 不是型式认可的雷达、自动雷达标绘仪、电子海图显示与信息系统或全球海上遇险与安全系统。
- 软件八扇区不等于物理多通道 360° 投影；视场、通道同步、时延和视觉系统尚未现场测量。
- 多学员网络目前只验证本机 UDP；没有生产加密网络或跨设备并发验收。
- 教员身份、资质、课程范围、签发机构和有效期均未提交，因此不声称认证教员体系或认可课程。
- 不具备实船、港口或生产控制权限。

## 运行边界

- 基础开放水域场景继续使用原三自由度运动模型，不启用高级任务附加力。
- 仅五个高级任务向原三自由度模型叠加有界浅水阻力、岸壁侧向力/艏摇力矩和教员注入的推进/操舵故障；这些是研究代理，不是指定船舶的实船标定结果。
- 不修改 45 维观测、动作空间或奖励。
- 不重训、替换或覆盖任何既有策略和失败记录。
- 自动舵与推进操作只调用已有执行控制接口。

## 复现

```bash
make GODOT="/Applications/Godot.app/Contents/MacOS/Godot" godot-full-mission-bridge-smoke
make full-mission-bridge-assurance-verify
.venv/bin/python -m unittest tests.test_full_mission_bridge -v
```

运行证据分别位于 `reports/godot_full_mission_bridge_smoke_v1.json` 和 `reports/full_mission_bridge_assurance_v1.json`。
